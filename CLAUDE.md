# Working on Math Mission

**Buildathon participants:** the rules below apply to the original app in `docs/web/`. For the participant app in `docs/starter/`, use the `tutor-kit-rules` skill (`.devin/skills/`) and `docs/starter/README.md` instead; `docs/sitemap.md` and `docs/roadmap.md` describe `docs/web/`, not `docs/starter/`.

## Rules for `docs/web/`

- **Start with the latest handoff** (linked from `README.md`), `docs/roadmap.md` and `docs/web/AGENTS.md`.
- **Check `docs/sitemap.md` before building anything.** Say where the work fits: which page, user action and capability. If it's new or changes how something works, add it to the site map's "Proposed changes" first and confirm with the tutor.
- **Keep the site map true.** When a page or capability is built, changed or dropped, update `docs/sitemap.md` (status, diagrams, change log) in the same commit, alongside the roadmap ticks.
- **Cost ideas go in `docs/cost-optimization.md`.** Add new ideas there as they come up, measure before acting (benchmark tokens), and update statuses and measured savings when one is done.
- Commit only when the tutor asks. Never print or commit keys.
