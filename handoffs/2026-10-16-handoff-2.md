## Decisions made in this stretch
- **Sign-in by email link, not code (for now).** Supabase locks email wording until the project has custom SMTP, and the default email only has a link. The login form still accepts a code (hidden under "Got a code instead?"). The intended email (link + code) is saved in `supabase/templates/magic_link.html`. **Own email service is now a Phase 3 roadmap item**, needed before inviting other families anyway: Supabase's built-in email only reaches Supabase team members, about 2 per hour.
- **Invites without emails:** `npm run invite` creates the account directly, so public sign-up stays off and no invite email template is needed.
- **Database enforces 011:** row-level security refuses all data until the adult has confirmed 18+ and accepted terms. The app also re-asks when `TERMS_VERSION` changes (the database only checks that both were accepted once).
- **Look:** Hologram HUD navy and cyan, toned down; light and dark follow the device. Space Grotesk headings, Geist body.
- **Benchmark lives in `web/`** and uses the app's own prompts; Gemini key moved from `benchmark/.env` to `web/.env.local`.
