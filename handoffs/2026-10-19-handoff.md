## Phase 2: first step
**Generation benchmark check** (roadmap, Phase 2). It's the one AI job not yet tested on real samples, and decision 010 depends on it.
- Add `web/src/prompts/generation.ts` from the outline in backend doc §8.2 ("Generation prompt") and [decision 010](../docs/decisions/010-question-generation.md): mirror the missed question, change only what decides the answer, the answer must differ, same skill and number size, valid answers, one right multiple-choice answer, diagrams described as data (`picture_spec`), JSON out.
- Extend `web/benchmark/` with a `generation` task. Its inputs are the missed questions in `test-data/graded-tests/*/expected.json`. Score each output on: valid JSON with the fields; the answer differs from the original; same format and number of choices; exactly one correct choice; and a **math check** for the question types in the samples (e.g. `value_of_digit`). Those checks become the app's Validation Rules later (backend doc §3.1, entity 12), so write them as reusable TypeScript, e.g. in `web/src/lib/checks/`, which the benchmark imports.
- Run it with `--dry-run` first, then a real run on `gemini-3.8-flash` only (costs a few cents). **Ask the tutor before any paid run.**
- Then continue down the Phase 2 list: upload → extraction → tutor review → generation → printable sheet → grading → review session → printables.

## Decisions made in this stretch
- **Sign-in by email link for now.** Supabase locks email wording without custom SMTP. The form also accepts a code; `supabase/templates/magic_link.html` (link + code) is ready for when there's an email service.
- **Own email service is a Phase 3 item.** Supabase's built-in email only reaches Supabase team members (about 2 per hour). `<tutor-email>` was added to the Supabase team as an owner for this reason.
- **Invites create accounts directly** (`npm run invite`); no invite emails.
- **The database enforces 011:** no data until the adult confirms 18+ and accepts terms. The app re-asks when `TERMS_VERSION` (`web/src/lib/terms.ts`) changes. `/terms` is a draft, to be legally reviewed before Phase 3.
- **Look:** Hologram HUD navy and cyan, toned down; light and dark follow the device; Space Grotesk headings, Geist body.

- **Secrets:** `web/.env.local` holds the Supabase URL, publishable and secret keys, and AI keys (Gemini set; Anthropic/OpenAI blank).
